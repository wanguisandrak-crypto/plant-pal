# Plant Pal

Plant Pal is a simple website for organizing your houseplants and finding basic care tips. Add plants with their names, species, locations, and watering frequency.
## ABOUT
plant pal was designed to help plant lovers effortlessly manage their collection ensuring every green friend gets the care and attention.


## FEATURES
- Add plant profile
- recording plant species
- setting watering reminders

## TECHNOLOGIES USED
- HTML 
- CSS
- JAVASCRIPT

## INSTALLATION 
Clawn the repository and open index.html in your browser

## USAGE
navigate to the dashboard to add new plant profiles,log species details and view upcoming watering schedules.
